# kali-linux-lab-setup
Cybersecurity Lab Environment Setup
Building an isolated virtual laboratory for cybersecurity, penetration testing, and ethical hacking practice

Project Overview

This project focuses on building and configuring an isolated cybersecurity laboratory using VirtualBox and Kali Linux 2026.3. The lab provides a controlled environment for practicing cybersecurity concepts, network reconnaissance, vulnerability assessment, penetration testing, and security-tool experimentation.

The environment is configured on a dedicated NAT Network (10.0.0.0/24) with Kali Linux assigned a consistent IP address (10.0.0.2). This setup allows additional virtual machines to be added as targets in future exercises while keeping security testing within a controlled and authorized environment.

The project also covers basic Linux network configuration, connectivity testing, DNS verification, and VM snapshot management to establish a reliable baseline for future cybersecurity labs.

Objective

Configure VirtualBox

Set up Kali Linux 2026.3

Create a dedicated NAT Network

Configure Kali networking

Assign 10.0.0.2/24

Verify connectivity

Verify cybersecurity tools

Create a clean snapshot

Document the environment for future labs
